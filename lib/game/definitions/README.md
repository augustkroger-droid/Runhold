# Game Definitions

Static game content belongs here, separate from player state.

Future examples:

- `resource-definitions.ts`
- `building-definitions.ts`
- `tech-definitions.ts`
- `raid-definitions.ts`
- `map-spawn-definitions.ts`
- `item-definitions.ts`

Definitions should describe what can exist in Runhold. They should not contain
per-player quantities, timers, progress, damage, or collected state.
